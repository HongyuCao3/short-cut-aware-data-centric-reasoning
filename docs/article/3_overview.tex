\section{Shortcut-Aware Reasoning Training}
\label{sec:method}

\begin{figure}[t]
    \centering
    \includegraphics[width=\linewidth]{figures/short_cut_aware_framework2.png}
    \caption{SART as a detection-then-correction framework for shortcut-aware reasoning training. \textbf{(A)} Per-sample gradients are read against a small validation gradient $\mathbf{g}_{\mathcal{V}}$ for non-transfer alignment and against a token-level partition for answer-gradient concentration. \textbf{(B)} The two signals combine into a unified \textsc{ShortcutScore} $S(s)$ that ranks samples by shortcut tendency. \textbf{(C)} A working set is selected by a single threshold on $S(s)$. \textbf{(D)} Per-sample, conflict-only gradient surgery fires only when $\mathbf{g}_s$ genuinely opposes $\mathbf{g}_{\mathcal{V}}$, removing only the conflicting component and preserving the validation-aligned residual that the same sample still carries. \textbf{(E)} Aggregated updates prioritize reasoning signals over shortcut patterns without dropping samples or scaling magnitudes.}
    \label{fig:overview}
\end{figure}

We take a gradient-geometry perspective: shortcut-aware reasoning training is not a sample-selection problem but a directional correction problem. A shortcut-prone sample is rarely purely harmful; its gradient typically mixes a validation-aligned component that supports reasoning with a conflicting component that promotes shortcut learning. Dropping the sample discards both; scalar reweighting shrinks both. SART instead acts at the level where the distinction lives---the per-sample gradient direction.
Figure~\ref{fig:overview} summarizes the resulting detection-then-correction framework. At the detection level, SART computes a \textsc{ShortcutScore} from two complementary gradient signals: non-transfer alignment with a small validation gradient $\mathbf{g}_{\mathcal{V}}$ and answer-gradient concentration on final-answer tokens. This score defines a working set of shortcut-prone samples. At the correction level, SART applies a per-sample, conflict-only projection that removes only the component of $\mathbf{g}_s$ opposing $\mathbf{g}_{\mathcal{V}}$, while preserving any validation-aligned residual. This converts shortcut mitigation from loss shaping or sample filtering into directional inference over the per-sample gradient field.
